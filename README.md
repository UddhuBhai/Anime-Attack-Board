# 🎮 Anime Attack Board

An interactive **Anime Attack Soundboard** built using **HTML**, **CSS**, and **JavaScript**. Trigger iconic anime attacks with your keyboard or mouse, complete with sound effects, visual animations, and a hidden transformation mode.

## 📖 About

**Anime Attack Board** brings some of the most iconic anime attacks into a single interactive experience. Each attack card is mapped to a keyboard key and features its own sound effect, color theme, and visual feedback.

To make the project even more fun, I added a hidden **Super Saiyan Mode**. Typing **"SSJ"** activates a secret transformation with glowing golden effects and a special transformation sound.

## 🚀 Features

* ⚔️ 12 iconic anime attacks
* ⌨️ Keyboard shortcuts for every attack
* 🖱️ Mouse click support
* 🔊 Individual sound effects
* 🌈 Attack-specific screen flash colors
* 📢 Animated attack banner
* ✨ Card press animations
* ⚡ Hidden Super Saiyan (SSJ) Mode
* 📱 Responsive design
